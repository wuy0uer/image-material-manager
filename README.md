# 图片素材库

Windows 本地图片素材管理工具，支持通用素材库、项目文件夹、分类标签、备注、组图，以及可选的 AI 分类和语义检索。

**当前版本：V1（1.0.0），Windows x64 便携版。**

## 下载与运行

在本仓库的 **Releases** 页面下载 `图片素材库.zip`，完整解压后运行 `图片素材库.exe`。不要只下载 GitHub 自动生成的 “Source code” 压缩包，也不要只复制 EXE。

无需另外安装 Node.js。AI 功能默认关闭，模型按需下载，发布包不包含模型、个人配置或素材。模型的运行速度和资源占用取决于电脑配置及所选模型。

## 主要功能

- 通用素材库：分类、标签、备注、收藏、锁定和组图。
- 项目文件夹：浏览、文件名搜索和文件整理。
- 关键字搜索、相似图搜索，以及可选的语义搜索与排序。
- 本地分类模型和外部 API 分析，详情页可先检查分析结果再保存。

项目中的文件操作可能改变真实文件，请备份重要素材。完整操作说明见 [使用说明](使用说明.txt)。
