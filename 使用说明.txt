图片素材库 · V1（1.0.1）
Windows 64 位便携版

一、开始使用
1. 完整解压“图片素材库”文件夹，双击“图片素材库.exe”。不要只复制 EXE，也不要在压缩包里直接运行。
2. 建议放在普通、可写的文件夹中。软件会在自己的目录下保存设置和缓存，请预留足够空间。
3. 选择通用素材库文件夹，或添加已有的项目文件夹。不要选择磁盘根目录。
4. 首次发布包不包含个人设置、图库和本地模型。首次运行生成 data 目录属于正常现象。

二、两种素材库
通用素材库：用于集中分类、打标签、添加备注、收藏和组图。导入的图片以副本存入图库，分类后由软件按规则命名、整理。
项目素材库：用于查看、搜索和整理已有项目文件夹。重命名、排序、移动等文件操作会影响项目中的真实文件，重要内容请先备份。
从资源管理器拖入图片或文件夹，也可以通过界面上的导入入口添加图片。

三、分类与搜索
可通过右键“分类”手动设置大类、子类、性别、标签和备注。详情页修改需要保存才生效。
启用 AI 后可使用 AI 分类；详情页可先分析、检查结果，再决定是否保存。分类结果仍建议人工核对。
通用库支持关键字搜索、分类及标签筛选；项目库按文件名搜索。搜索与筛选可以搭配使用，“清除筛选”可在适用时保留搜索，“查看全部”可重置当前条件。
相似图搜索需要分类模型分析参考图；启用语义功能时按语义检索，否则使用规则检索。

四、AI 模型与 API
分类功能和语义功能首次默认关闭，不使用 AI 也可以进行基本管理和手动分类。
打开“模型设置”，按需要下载分类模型和语义模型，或添加兼容的自定义分类模型、配置 API。模型下载、API 请求需要联网，使用 API 可能由服务商收费。
本地模型文件较大，需要足够的磁盘空间、内存和适配的硬件；实际速度取决于模型、图片和电脑配置。
语义模型处理图片的文字信息，用于搜索与排序；它不会直接读取图片。使用语义搜索前需要按界面提示建立索引。
模型支持分别设置闲置后的自动释放时间。

五、常用操作
主界面：单击选择，Ctrl 增减选择，Shift 连选，Alt 拖动框选，Ctrl+A 全选当前结果。
右键菜单提供当前场景可用的分类、复制、移动、编组等操作。删除图片会送到 Windows 回收站；需要恢复时请先检查回收站。
“撤销”或 Ctrl+Z 可撤销当前支持的最近一次操作，不等于完整历史恢复。
手动排序中可拖动预览，Esc 或右键取消当前拖动；是否立即保存以当前界面的按钮和模式为准。

六、备份、搬迁与更新
软件目录中的 data 保存设置、API 配置、导航和运行数据；本地模型保存下载的模型。需要保留使用状态时，请一并备份。
图库内“.素材库数据”和项目内“.图片素材库数据”保存标签、备注、分组等整理记录，不要当作垃圾删除。搬迁图库时请连同隐藏数据目录完整复制。
后续更新前先退出软件并备份。只替换新版提供的程序文件，保留原 data、本地模型、外部模型和全部素材库；不要先删除原软件文件夹，也不要使用镜像删除式覆盖工具。
向他人分享本软件时请使用干净发布包，不要直接压缩自己使用过的软件目录，避免分享个人图库路径、API 配置和缓存。

本软件为便携应用，不需要安装 Node.js。请保留随包运行组件与第三方许可证文件。
